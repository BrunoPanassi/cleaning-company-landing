---
title: 'Why not v-autocomplete?'
description: 'The most simple and complete input component that you need'
date: '2026-04-09'
---

I say this because these two components, as found in the documentation, reference each other as "Look, you can choose this one too," but it's shown alongside v-autocomplete, which is much more useful.

In one project, I was using v-combobox, but I needed that if what the user typed wasn't found in the list and therefore not selected, what they typed shouldn't be selected. However, with v-combobox, this was proving very cumbersome.

By switching to v-autocomplete, I didn't need to do anything; it already understands that it won't be selected, in addition to other functionalities it already provides.

So next time, consider using v-autocomplete.
